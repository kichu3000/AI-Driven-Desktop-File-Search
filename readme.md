# AI File Search

A desktop application built with Electron, React, and Vite that allows users to search for files on their local system. It features an intuitive interface and optional AI-assisted search capabilities to enhance file discovery.

## Features

-  Search files on your local system
-  Optional AI-assisted search using a free API
-  Open files directly from search results
-  Show files in their containing folder

## Installation

```bash
git clone https://github.com/kichu3000/AI-Driven-Desktop-File-Search.git
cd AI-Driven-Desktop-File-Search
npm install
```

## Usage

### Just want to use the app?

Download the installer from the [Download](#download) section above, run it, and launch **AI File Search** like any other desktop app.

### Want to edit the code?

If you'd like to modify the source or run it from code:

```bash
npm run start
```

To build your own installer using `electron-builder`:

```bash
npm run build
```
